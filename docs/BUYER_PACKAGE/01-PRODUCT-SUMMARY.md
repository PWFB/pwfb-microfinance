# Product Summary

PWFB Microfinance is a web and Android-oriented microfinance management platform covering customer management, savings/deposits, withdrawals, transfers, lending, repayments, staff operations, banking integrations and administrative controls.

## Core workflow targets
1. Customer → Account → Deposit → Withdrawal → Transfer
2. Customer → Loan → Approval → Disbursement → Repayment → Outstanding balance
3. Staff → Client → Payment type → Cash/Deposit → Amount → Date → Reconciliation
4. Credit Officer → Loan → Branch Manager review/edit → Outstanding clients
5. Banking, ATM-card and virtual-account workflows

Final feature claims must come from the accepted release candidate.
