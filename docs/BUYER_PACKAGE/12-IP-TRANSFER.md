# IP Transfer Checklist

- Repository and release history
- Domains/deployment accounts if included
- Database and credentials
- Payment-provider ownership
- Google OAuth ownership
- Android signing keys
- App-store ownership
- Brand assets
- Documentation
- Third-party/open-source licenses
- AI/provider accounts and rights
- Final source archive
- Data export

Legal ownership, warranties, liabilities and included assets belong in the sale agreement.
